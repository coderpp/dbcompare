# 连接与方案导入导出

入口：顶部“连接与方案”。

- **导出全部**：导出所有连接与方案为一个 JSON 配置包。
- 连接卡片的**导出**：只导出该连接。
- 方案卡片的**导出**：导出该方案及它引用的源、目标连接；同一连接只包含一次。
- **导入配置**：选择 JSON，预览连接、方案、源/目标库和同名提示，再点“确认导入”。取消预览不会写入。

导入采用新增方式，自动生成本机 ID 并重建方案对连接的引用。同名项添加“（导入 1）”等后缀；重复导入也会新增，不覆盖现有连接、密码或方案。整个导入在同一事务内完成，失败时不会留下部分配置。

每次导出前显示选项，**“包含已保存的连接密码”默认不勾选**。勾选后 JSON 会包含明文密码，文件名增加 `-with-passwords`，选项在导出后复位。请仅通过可信方式传递这类文件。默认导出仍不读取、不包含密码。

含密码文件导入时，预览只提示哪些连接携带密码，不回显内容；确认后将密码写入新连接的系统凭据存储，不覆盖已有连接的密码。凭据写入失败会回滚并清理本次新增项。如果系统凭据存储不可用而降级为内存保存，界面会明确提示重启后需重新填写。未携带密码的连接需编辑补充密码。仅导入配置不会连接数据库或执行同步。

字符集、排序规则、超时等可移植驱动参数会保留；自定义会话参数、证书/密钥配置或本机专用注册项不随包迁移，导入/导出会给出提示，需要在目标机补充。

格式标识为 `dbcompare-settings`，无密码包版本为 `1`；含密码包使用版本 `2` 并带 `includesPasswords: true` 标记，需使用 0.1.3 或更新版本导入。旧版会拒绝版本 2 文件，避免静默丢失密码。版本 1 文件中的额外密码字段仍按旧行为忽略。会拒绝不支持的版本、无效连接、重复 ID、缺少依赖连接的方案和超过 8 MB 的文件。旧的单独方案 JSON 缺少完整连接信息，请使用当前界面重新导出。

配置包包含服务器地址、用户名、库名等配置，转移时请交给可信的接收方。它不包含数据库结构、业务数据或执行历史；密码是否包含取决于导出时的勾选项。
