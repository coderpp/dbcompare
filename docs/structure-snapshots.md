# 结构快照（0.2.0）

入口：顶部“结构快照”，默认打开快照库。

## 使用

1. “立即采集”：选已有连接、多选数据库、点“添加到采集列表”；可以继续切换连接添加更多库，然后开始采集。完成后在执行记录查看逐库结果。
2. “定时任务 → 新增任务”：指定数据库列表、小时/每日/每周周期、保留天数。按电脑当前时区执行。
3. 需要退出窗口后仍采集时，先点“开启 macOS 后台调度”，再在任务中勾选“后台执行”。仅应用运行时的任务不会由后台程序执行。
4. 快照库按数据库分组；浏览和历史对比不连接原数据库。点击版本查看原始 DDL，可写备注、标记重要版本。重要版本不会自动清理。
5. 勾选两份版本，按时间由旧到新进行结构模型对比；也可选择任意实际连接/数据库，查看当前库相对该快照的变化。
6. “以此快照为期望结构”重新读取实际目标，进入原有同步工作台；默认不选择表，不允许删除，不执行 SQL。审阅后按原流程生成计划和确认执行。同步后的失败继续处理会重新读取该快照和实际目标。
7. 快照包支持导入/导出，导入不会绑定包中的连接 ID 到本机连接；需要与当前库对比时手动选择本机连接。也可导出原始结构 SQL、差异 JSON 报告。

## 调度与存储

- macOS LaunchAgent：`~/Library/LaunchAgents/com.pp.dbcompare.snapshots.plist`，登录会话内每分钟检查到期任务；使用 `/Applications/DB Compare.app/Contents/MacOS/dbcompare --snapshot-worker` 和当前配置目录，无窗口、无 HTTP 服务。必须将应用保留在安装路径。
- 电脑睡眠或关机不会采集；恢复后只补采一次，不伪造遗漏时间的历史结构。不开机、不登录时无法运行。
- 应用和后台共享 SQLite 原子任务租约。逐库续租，过期旧持有者不能续用或释放新租约；同一进程也不能重复取得任务锁。
- 手动执行不改变原定下次时间；暂停、修改任务会根据当前时间重新计算计划。
- 多库独立结果，失败保留之前的快照，可重试失败项。意外退出可能留下“执行中或已中断”的记录，租约到期后可重新执行任务。
- 使用已保存连接与系统钥匙串；后台无法读取凭据时记录失败，不将密码放入任务、快照包或 LaunchAgent。
- 采集按“连接 + 数据库”与最近一份快照比较：结构未变化时复用已有版本，不新增快照记录或压缩内容，更新“最近备份”时间，并保存本次执行记录、显示“结构未变化，复用已有快照”。原版本生成时间、备注和重要标记保持不变；详情同时显示最近备份和版本生成时间。首次采集或结构变化时才保存新版本。结构从 A 改为 B 再恢复 A 也会记录一个新版本。
- SQLite 的结构内容 gzip 压缩、SHA256 去重。结构判定忽略自增计数增长和服务器版本等采集信息，仍检查字段、索引、注释、字符集、顺序和原始分区 DDL。新版本保留采集时的原始 DDL 和自增计数。
- 自动清理只针对对应定时任务；保留重要版本，并至少保留每个数据库最新一份。手动/导入快照不自动清理。
- 导入包上限 64 MB / 100 份；验证版本、内容散列、时间、表 DDL 和模型一致性，整包事务保存。单库结构上限 64 MB。

## 范围

仅采集当前账户可见的基础表，包括原始建表 SQL、Atlas HCL 结构模型、字段、主键、索引、外键、可识别约束、表属性和注释，以及数据库字符集/排序规则、服务器版本和大小写规则。不含表内数据、视图、触发器、过程或事件。基础表清单、两轮 DDL 与两轮模型不一致时采集失败，不保存为成功快照。

原始分区 DDL 保留，但当前结构模型和同步引擎不覆盖分区变更。离线 SQL 预览使用 MySQL 8.0 方言，仅供审阅；实际同步使用目标数据库驱动重新规划和预检查。快照不能恢复已删除的数据，也不是可直接执行的回滚脚本。
